# InvestorView

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

一款行情筛选应用：在浏览器中进行本地看图和选股。它运行在你自己的电脑上，不需要账号或 API 密钥，除 Node.js 外没有任何依赖。

- **桌面版（全部功能）：** 从[最新发布](https://github.com/RockAlter/Investerview/releases/latest)下载 `InvestorView.exe`，或按下文说明从源码运行。
- **网页版：** <https://rockalter.github.io/Investerview/> —— 无需安装；支持股票、ETF、指数和加密货币，但有少量限制。见[网页版及其限制](#网页版及其限制)。

## 功能

- **图表** —— 13 种图表类型：K 线、空心 K 线、平均 K 线（Heikin Ashi）、美国线、HLC 线、最高-最低、折线、带标记的线、阶梯线、面积图、基准线、柱状图和砖形图（Renko，砖块大小为 14 根 K 线的 ATR）；周期从 1 分钟到 1 个月；普通、对数、百分比和以 100 为基准的价格坐标。
- **对比** —— 最多可把 4 个其他代码以折线形式加到图表上（例如 NVDA 对比 SPY）。每条线从屏幕左边缘处当前图表代码的价格开始，因此可以看出此后谁的涨跌幅更大。
- **多图表布局** —— 同时显示 1 个、2 个（左右并排或上下排列）或 4 个图表。每个图表有各自的代码、周期、图表类型和指标；画线是共用的。先点击某个图表，再点击自选列表中的代码，即可在该图表中打开。
- **提醒** —— 在 **提醒** 标签页中，可为某个代码设置以下提醒：
  - 价格到达某个水平（也可在图表上该价格处点击右键；提醒会以可拖动的线条画在图表上）；
  - 今日涨幅或跌幅达到某个百分比；
  - 日线 RSI（14）升破或跌破某个值；
  - 价格穿过 50 日或 200 日均线；
  - 价格穿过你画的趋势线或水平线：右键点击该线，选择“价格穿过此线时提醒”。该线会在其所画的周期上向未来延伸。

  提醒触发时，应用会显示消息、播放提示音，并（在你允许的情况下）显示 Windows 通知。提醒大约每 20 秒检查一次，且仅在应用打开时检查。
- **成交量分布** —— 在指标列表中：图表右侧的横向柱状图，显示屏幕上这些 K 线在各个价位的成交量（绿色为上涨 K 线，红色为下跌 K 线），并标出成交量最大的价位（POC）。
- **模拟账户业绩** —— 模拟标签页会画出账户净值随时间的变化，并显示最大回撤、胜率、平均盈利和亏损、盈亏比、最佳和最差交易，以及各代码的已实现盈亏。
- **访问计数（仅网页版）** —— 网页版每次访问会向数据代理报告一次，数据代理只保存匿名的每日总数：访问次数、访客数、新访客数以及各国家/地区的次数。不保存 IP 地址、Cookie 或任何标识。桌面版不报告任何信息。
- **盘前盘后** —— 桌面版始终显示股票和 ETF 在 1 分钟至 1 小时图上的盘前、盘后 K 线（美东时间 4:00–20:00），以阴影标出，并在自选列表中显示最新的盘前盘后价格。该数据源不提供夜盘数据。
- **语言** —— English、简体中文、繁體中文和日本語。界面自动跟随浏览器/系统语言，也可在顶栏的选择框中手动切换。翻译文本在 `public/i18n.js` 中。
- **浅色和深色主题** —— 跟随系统设置；顶栏的 ☀ / ☾ 按钮可切换并记住你的选择。
- **版本号** —— 当前运行的版本显示在左侧工具栏底部。桌面版大约每天向 GitHub 查询一次最新版本号；有新版本时，版本号会变为 `↑ v…` 并链接到下载页面。不会自动下载或安装任何内容。
- **指标** —— 共 25 个。叠加在价格图上：SMA、EMA、WMA、线性回归线、VWAP、布林带、唐奇安通道、肯特纳通道、超级趋势、抛物线 SAR、成交量。图表下方：RSI、MACD、随机指标 KD、CCI、威廉 %R、MFI、ADX/DMI、ATR、标准差、ROC、动量、OBV。周期可修改。
- **画线工具** —— 共 25 个，在左侧工具栏中分组：线条（趋势线、射线、延长线、箭头、水平线、水平射线、垂直线、十字线）、通道（平行通道、回归通道 ±2σ、安德鲁音叉线）、斐波那契与江恩（回撤、扩展、扇形线、时间周期、江恩角度线）、形状（矩形、椭圆、三角形）、测量（测量、价格范围、日期范围、带风险收益比的多头/空头仓位、锚定 VWAP）和文字。选中画线后可拖动控制点调整。画线按代码保存，切换周期后仍然保留。
- **模拟交易** —— 侧栏的 **模拟** 标签页提供一个使用虚拟资金的模拟账户（初始 100,000，可重置）。可用市价单、限价单和止损单买入、卖出或做空当前图表的代码；查看持仓、平均成本、已实现和未实现盈亏以及成交记录；平均成本和挂单会画在图表上。不会向任何券商发送委托。委托按应用掌握的最新价格成交（休市时也是如此），限价单和止损单在应用打开期间约每 20 秒检查一次；不支持融资，不计手续费，不做货币换算。
- **自选列表** —— 分组、拖动排序、实时最新价和当日涨跌。**+ 添加** 可搜索任意代码并放入所选分组；分组标题上的 **+** 会把当前图表的代码加入该分组；右键点击代码可将其移到其他分组。
- **导入** —— 读取从 TradingView 导出的自选列表（`交易所:代码` 文本，包括 `###分组` 标题）并转换代码。
- **筛选器** —— 扫描美股大盘股、ETF、加密货币、外汇/商品、日本大盘股、你的自选列表或自定义列表；可按价格、涨跌幅、RSI、相对成交量、距 52 周高点的距离以及相对 50/200 日均线的位置筛选。

## 网页版及其限制

<https://rockalter.github.io/Investerview/> 是发布在 GitHub Pages 上的同一套界面。任何浏览器都能打开，无需安装。

**价格从哪里来。** 浏览器不允许网页读取其他网站的数据，除非对方明确允许（CORS 规则）。Yahoo Finance、Nasdaq 和大多数股票数据源都不允许，所以网页版会使用多个数据源并自动切换。某个数据源出错时会被跳过两分钟，改用下一个：

| 顺序 | 数据源 | 覆盖范围 |
|---|---|---|
| 加密货币 | Binance，其次 Coinbase（浏览器直接获取） | 以美元计价的加密货币，全部周期 |
| 1 | **InvestorView 数据代理** —— 一个小型 Cloudflare Worker（[`worker/`](worker/README.md)），代替网页依次向 Yahoo Finance、Nasdaq、腾讯请求数据 | 桌面版能显示的全部内容，包括分时、外汇、期货和代码搜索 |
| 2 | 腾讯财经（浏览器直接获取） | 美股和 ETF、标普 500 / 道琼斯 / 纳斯达克 / 恒生指数、港股和 A 股；日线、周线、月线 |
| 3 | 通过公共代理 AllOrigins 访问 Yahoo Finance | 全部内容，但速度慢且经常不可用 |

当前使用的数据源显示在图表上方的图例行中。

| | 网页版 | 桌面版 |
|---|---|---|
| 股票、ETF、指数、加密货币（日线、周线、月线） | 支持 | 支持 |
| 分时图（1 分钟–1 小时）、外汇、期货、代码搜索 | 能连上数据代理（或 AllOrigins）时支持；加密货币分时始终支持 | 支持 |
| 盘前盘后价格 | 不支持 | 支持 |
| 筛选器 | 全部内置列表 | 全部内置列表 |
| 导入自选列表 | 不支持 | 支持 |
| IBKR 持仓和订单 | 不支持 | 支持 |
| 供 AI 应用使用的 MCP 服务 | 不支持 | 支持 |
| 自选列表和画线的保存位置 | 只在当前浏览器中：没有备份，也不会与其他浏览器、设备或桌面版共享 | 浏览器和磁盘上的数据文件 |
| 图表类型、指标、画线工具、语言、主题 | 支持 | 支持 |

关于网页版的其他说明：

- 备用数据源的价格可能与 Yahoo 略有差异（加密货币来自单一交易所；分红调整方式不同），且备用数据源显示的是代码而不是公司名称。
- 网页版就是发布到 `gh-pages` 分支的 `public/` 目录；`public/web-data.js` 是它的数据层，文件开头的 `PROXY_URL` 是数据代理的地址。

## 运行

需要 [Node.js](https://nodejs.org) 18 或更高版本。

```bash
node server.js
```

然后打开 <http://localhost:5178>。在 Windows 上也可以直接双击 `start.bat`。设置环境变量 `PORT` 可以使用其他端口。

## 构建独立的 .exe

要把应用交给没有安装 Node.js 的人，可以构建单文件可执行程序：

```bash
npm run build
```

它会生成 `dist/InvestorView.exe`（约 80 MB，因为包含了 Node 运行时）。构建过程会通过 `npx` 下载一个辅助工具 [postject](https://github.com/nodejs/postject)。构建过程还会通过 `npm` 下载 [rcedit](https://github.com/electron/rcedit)，用来给 exe 设置图标和名称。双击 exe 会在独立窗口中打开应用，没有控制台，也不占用浏览器标签页；关闭窗口即停止运行。这个窗口是应用模式下的 Microsoft Edge（Windows 自带）或 Chrome，使用独立的浏览器配置。如果两者都没有安装，或使用 `--browser` 参数，应用会改在默认浏览器中打开，并在页面关闭十分钟后自动停止。

该 exe 没有代码签名，首次运行时 Windows SmartScreen 会发出警告（点击“更多信息”→“仍要运行”）。

## 在 AI 应用中使用（MCP）

同一个程序也是一个 [Model Context Protocol](https://modelcontextprotocol.io) 服务，因此 Claude Desktop、Claude Code 等 AI 应用可以读取行情数据、运行筛选、读取你保存的自选列表和画线，然后据此撰写报告。它是只读的：没有任何工具会下单或修改你的数据。

用 `--mcp` 参数启动（此时它通过标准输入/输出通信，不会打开网页界面）。把下面的内容加入 AI 应用的 MCP 设置，并换成 exe 的实际路径：

```json
{
  "mcpServers": {
    "investerview": {
      "command": "C:\\path\\to\\InvestorView.exe",
      "args": ["--mcp"]
    }
  }
}
```

如果从源码运行：`"command": "node", "args": ["C:\\path\\to\\server.js", "--mcp"]`。

| 工具 | 返回内容 |
|---|---|
| `search_symbols` | 与公司名称匹配的代码 |
| `get_quote` | 价格、涨跌、成交量、RSI、均线、52 周位置、盘前盘后价格（最多 25 个代码） |
| `get_price_history` | 任意周期的 OHLCV K 线，可选包含盘前盘后 |
| `get_technicals` | SMA 20/50/200、EMA 20、RSI 14、MACD、布林带 |
| `run_screener` | 对内置列表、你的自选列表或自定义列表进行筛选和排序 |
| `get_watchlist` | 按分组列出你的自选列表及报价 |
| `get_drawings` | 你保存的画线：线条、价格水平线、通道、仓位、文字备注和斐波那契水平 |
| `get_alerts` | 你的提醒（价格、今日涨跌幅、RSI、均线、画线）：等待中的和已触发的 |

还有一个现成的提示词 `watchlist_report`。也可以直接说：“根据我的 InvestorView 自选列表写一份晨报”。

自选列表和画线工具读取的是下文所述的数据文件，所以请先至少打开一次桌面版。

## 盈透证券（IBKR）持仓（只读）

侧边栏的 **持仓** 标签页显示你的 IBKR 账户：余额、持仓及未实现盈亏、未成交订单。在图表上，持有的品种会在你的平均成本处显示一条虚线，每个未成交订单会在其价格处显示一条线。

它是只读的。应用只能向 IBKR 发送固定的一组读取请求（见 `server.js` 中的 `IB_READONLY`）；不能下单、改单或撤单。

每个交易日的设置步骤：

1. 下载 IBKR 的 **Client Portal Gateway**（见 IBKR 的 [Web API 文档](https://www.interactivebrokers.com/docs/web-api)）并解压。它需要 Java 和 IBKR Pro 账户。
2. 在它的目录中启动：`bin\run.bat root\conf.yaml`
3. 在 <https://localhost:5000> 登录。浏览器在这里提示证书警告是正常的。使用模拟交易用户名可以查看模拟账户。
4. 打开“持仓”标签页并点击“重试”。

说明：

- 你的 IBKR 密码只会输入到 IBKR 自己的登录页面；本应用不会接触到它。
- 持仓和余额只需要 IBKR 的只读会话，因此不会打断 TWS 或手机端的登录。未成交订单和当日盈亏只有在网关中已有交易会话时才会显示；本应用不会主动开启交易会话。
- 网关必须运行在同一台电脑上。如果你改了端口，请使用 `--ibkr=https://localhost:5001`（或 `IBKR_GATEWAY`）。
- IBKR 大约每天会让网关登出一次。
- MCP 服务不提供账户数据。

## 数据保存在哪里

在桌面版中，自选列表、画线和指标设置保存在浏览器里，并同步到一个文件：Windows 上是 `%APPDATA%\Investerview\data.json`，其他系统是 `~/.config/Investerview/data.json`（可用 `INVESTERVIEW_DATA` 修改）。启动时以文件为准，所以清除浏览器数据不会丢失，同一台电脑上的不同浏览器也共用这份数据。复制这个文件即可备份或迁移到另一台电脑。

网页版没有数据文件：所有内容都只保存在当前浏览器的本地存储中。

## 数据来源和限制

- 价格来自 Yahoo Finance 的公开网页接口，由 `server.js` 转发；Yahoo 不可用时使用备用数据源（见“故障排查”）。这些接口是非官方的、不受支持的：可能变更、限流或停止工作，报价也可能有延迟（部分交易所延迟 15–20 分钟）。
- 日内历史数据有限：1 分钟 K 线约 5 天，5/15 分钟 K 线约一个月，小时 K 线约 6 个月。
- 图表库（[Lightweight Charts](https://github.com/tradingview/lightweight-charts)，Apache-2.0）从 CDN 加载，因此应用需要联网。
- 上次查看的代码、周期和语言等图表设置只保存在浏览器的本地存储中。
- 这只是一个看图和筛选工具。它不会下单，其中任何内容都不构成投资建议。

## 故障排查：没有价格、“HTTP 403”或“被拒绝”

Yahoo Finance 会拒绝来自某些网络的请求：某些 VPN 出口、公司或学校代理、云服务器和数据中心地址，以及部分地区。应用在放弃之前会尝试四条线路（两台 Yahoo 服务器，各自带或不带会话 cookie），所以多数情况会自行恢复。如果图表仍显示“Yahoo Finance 拒绝了请求”：

- 打开或关闭 VPN/代理，或换一个 VPN 节点，然后刷新。
- 等几分钟：请求过多时 Yahoo 可能暂时封锁某个地址。
- 打开 `http://localhost:5178/api/diag`（即“查看连接诊断”链接），查看每条线路的返回结果。其中不含个人数据，求助时可以放心分享。

### 备用数据源

当 Yahoo 拒绝请求或无法连接时，桌面版会自动切换到其他公开数据源，图表上会显示“备用数据源”标签并注明当前使用的来源：

| 来源 | 覆盖范围 | 周期 |
|---|---|---|
| Binance，其次 Coinbase | 以美元计价的加密货币（`BTC-USD`） | 全部 |
| Nasdaq | 美股和 ETF | 日线、周线、月线（10 年） |

使用备用数据时的限制：美股没有日内图表（1 分钟至 1 小时）；美国以外的股票、指数、外汇和期货完全没有数据；没有盘前盘后价格，没有代码搜索（请直接输入代码），也没有公司名称。价格可能与 Yahoo 略有差异（加密货币来自单一交易所；分红复权方式不同）。

1.5.0 版还包含一个实验性的东方财富（Eastmoney）数据源，用于指数、外汇、期货和日内 K 线。它已在 1.5.1 中移除：东方财富在短时间的一小批请求之后把来源地址封锁了三个多小时，无法作为备用数据源使用。

应用直接连接 Yahoo。它不会使用只在浏览器或 Windows 设置中配置的代理；全局（TUN）模式的 VPN 则会生效。
