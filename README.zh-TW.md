# Investerview

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

一款行情篩選應用程式：在瀏覽器中進行本機看圖和選股（介面上的名稱是 **ChartDesk**）。它執行在你自己的電腦上，不需要帳號或 API 金鑰，除 Node.js 外沒有任何相依套件。

- **桌面版（全部功能）：** 從[最新發行版](https://github.com/RockAlter/Investerview/releases/latest)下載 `Investerview.exe`，或依下文說明從原始碼執行。
- **網頁版：** <https://rockalter.github.io/Investerview/> —— 無需安裝；支援股票、ETF、指數和加密貨幣，但有少量限制。見[網頁版及其限制](#網頁版及其限制)。

## 功能

- **圖表** —— 13 種圖表類型：K 線、空心 K 線、平均 K 線（Heikin Ashi）、美國線、HLC 線、最高-最低、折線、帶標記的線、階梯線、面積圖、基準線、柱狀圖和磚形圖（Renko，磚塊大小為 14 根 K 線的 ATR）；週期從 1 分鐘到 1 個月；一般、對數、百分比和以 100 為基準的價格座標。
- **比較** —— 最多可把 4 個其他代號以折線形式加到圖表上（例如 NVDA 比較 SPY）。每條線從畫面左邊緣處目前圖表代號的價格開始，因此可以看出此後誰的漲跌幅更大。
- **多圖表版面** —— 同時顯示 1 個、2 個（左右並排或上下排列）或 4 個圖表。每個圖表有各自的代號、週期、圖表類型和指標；畫線是共用的。先點選某個圖表，再點選自選清單中的代號，即可在該圖表中開啟。
- **價格警示** —— 在 **警示** 分頁中，或在圖表上按右鍵，為某個代號設定價格。價格到達時，應用會顯示訊息、播放提示音，並（在你允許的情況下）顯示 Windows 通知；警示會以線條形式畫在圖表上。警示大約每 20 秒檢查一次，且僅在應用開啟時檢查。
- **成交量分布** —— 在指標清單中：圖表右側的橫向柱狀圖，顯示畫面上這些 K 線在各個價位的成交量（綠色為上漲 K 線，紅色為下跌 K 線），並標出成交量最大的價位（POC）。
- **模擬帳戶績效** —— 模擬分頁會畫出帳戶淨值隨時間的變化，並顯示最大回撤、勝率、平均獲利和虧損、獲利因子、最佳和最差交易，以及各代號的已實現損益。
- **造訪計數（僅網頁版）** —— 網頁版每次造訪會向資料代理回報一次，資料代理只保存匿名的每日總數：造訪次數、訪客數、新訪客數以及各國家/地區的次數。不保存 IP 位址、Cookie 或任何識別資訊。桌面版不回報任何資訊。
- **盤前盤後** —— 可選擇顯示股票和 ETF 在 1 分鐘至 1 小時圖上的盤前、盤後 K 線（美東時間 4:00–20:00），以陰影標示，並在自選清單中顯示最新的盤前盤後價格。此資料來源不提供夜盤資料。
- **語言** —— English、简体中文、繁體中文和日本語。介面自動跟隨瀏覽器/系統語言，也可在頂端列的選單中手動切換。翻譯文字在 `public/i18n.js` 中。
- **淺色和深色主題** —— 跟隨系統設定；頂端列的 ☀ / ☾ 按鈕可切換並記住你的選擇。
- **版本號** —— 目前執行的版本顯示在左側工具列底部和主控台視窗中。
- **指標** —— 共 25 個。疊加在價格圖上：SMA、EMA、WMA、線性迴歸線、VWAP、布林通道、唐奇安通道、肯特納通道、超級趨勢、拋物線 SAR、成交量。圖表下方：RSI、MACD、隨機指標 KD、CCI、威廉 %R、MFI、ADX/DMI、ATR、標準差、ROC、動量、OBV。週期可修改。
- **畫線工具** —— 共 25 個，在左側工具列中分組：線條（趨勢線、射線、延長線、箭頭、水平線、水平射線、垂直線、十字線）、通道（平行通道、迴歸通道 ±2σ、安德魯音叉線）、費波那契與江恩（回撤、擴展、扇形線、時間週期、江恩角度線）、形狀（矩形、橢圓、三角形）、測量（測量、價格範圍、日期範圍、含風險報酬比的多頭/空頭部位、錨定 VWAP）和文字。選取畫線後可拖曳控制點調整。畫線依代號儲存，切換週期後仍然保留。
- **模擬交易** —— 側欄的 **模擬** 分頁提供一個使用虛擬資金的模擬帳戶（初始 100,000，可重設）。可用市價單、限價單和停損單買進、賣出或放空目前圖表的代號；查看持倉、平均成本、已實現和未實現損益以及成交紀錄；平均成本和掛單會畫在圖表上。不會向任何券商送出委託。委託以應用掌握的最新價格成交（休市時也是如此），限價單和停損單在應用開啟期間約每 20 秒檢查一次；不支援融資，不計手續費，不做貨幣換算。
- **自選清單** —— 分組、拖曳排序、即時最新價和當日漲跌。
- **匯入** —— 讀取從 TradingView 匯出的自選清單（`交易所:代號` 文字，包括 `###分組` 標題）並轉換代號。
- **篩選器** —— 掃描美股大型股、ETF、加密貨幣、外匯/商品、日本大型股、你的自選清單或自訂清單；可依價格、漲跌幅、RSI、相對成交量、距 52 週高點的距離以及相對 50/200 日均線的位置篩選。

## 網頁版及其限制

<https://rockalter.github.io/Investerview/> 是發布在 GitHub Pages 上的同一套介面。任何瀏覽器都能開啟，無需安裝。

**價格從哪裡來。** 瀏覽器不允許網頁讀取其他網站的資料，除非對方明確允許（CORS 規則）。Yahoo Finance、Nasdaq 和大多數股票資料來源都不允許，所以網頁版會使用多個資料來源並自動切換。某個資料來源出錯時會被跳過兩分鐘，改用下一個：

| 順序 | 資料來源 | 涵蓋範圍 |
|---|---|---|
| 加密貨幣 | Binance，其次 Coinbase（瀏覽器直接取得） | 以美元計價的加密貨幣，全部週期 |
| 1 | **Investerview 資料代理** —— 一個小型 Cloudflare Worker（[`worker/`](worker/README.md)），代替網頁依序向 Yahoo Finance、Nasdaq、騰訊請求資料 | 桌面版能顯示的全部內容，包括分時、外匯、期貨和代號搜尋 |
| 2 | 騰訊財經（瀏覽器直接取得） | 美股和 ETF、標普 500 / 道瓊 / 那斯達克 / 恒生指數、港股和 A 股；日線、週線、月線 |
| 3 | 透過公共代理 AllOrigins 存取 Yahoo Finance | 全部內容，但速度慢且經常無法使用 |

目前使用的資料來源顯示在圖表上方的圖例列中。

| | 網頁版 | 桌面版 |
|---|---|---|
| 股票、ETF、指數、加密貨幣（日線、週線、月線） | 支援 | 支援 |
| 分時圖（1 分鐘–1 小時）、外匯、期貨、代號搜尋 | 能連上資料代理（或 AllOrigins）時支援；加密貨幣分時一律支援 | 支援 |
| 盤前盤後價格 | 不支援 | 支援 |
| 篩選器 | 全部內建清單 | 全部內建清單 |
| 匯入自選清單 | 不支援 | 支援 |
| IBKR 持倉和訂單 | 不支援 | 支援 |
| 供 AI 應用使用的 MCP 服務 | 不支援 | 支援 |
| 自選清單和畫線的儲存位置 | 只在目前的瀏覽器中：沒有備份，也不會與其他瀏覽器、裝置或桌面版共用 | 瀏覽器和磁碟上的資料檔 |
| 圖表類型、指標、畫線工具、語言、主題 | 支援 | 支援 |

關於網頁版的其他說明：

- 備用資料來源的價格可能與 Yahoo 略有差異（加密貨幣來自單一交易所；股利調整方式不同），且備用資料來源顯示的是代號而不是公司名稱。
- 網頁版就是發布到 `gh-pages` 分支的 `public/` 目錄；`public/web-data.js` 是它的資料層，檔案開頭的 `PROXY_URL` 是資料代理的位址。

## 執行

需要 [Node.js](https://nodejs.org) 18 或更新版本。

```bash
node server.js
```

然後開啟 <http://localhost:5178>。在 Windows 上也可以直接按兩下 `start.bat`。設定環境變數 `PORT` 可以使用其他連接埠。

## 建置獨立的 .exe

要把應用程式交給沒有安裝 Node.js 的人，可以建置單一檔案的可執行程式：

```bash
npm run build
```

它會產生 `dist/Investerview.exe`（約 80 MB，因為包含了 Node 執行環境）。建置過程會透過 `npx` 下載一個輔助工具 [postject](https://github.com/nodejs/postject)。按兩下 exe 即可啟動應用程式並在預設瀏覽器中開啟；關閉它的主控台視窗即停止執行。

該 exe 沒有程式碼簽章，首次執行時 Windows SmartScreen 會發出警告（點選「其他資訊」→「仍要執行」）。

## 在 AI 應用程式中使用（MCP）

同一個程式也是一個 [Model Context Protocol](https://modelcontextprotocol.io) 服務，因此 Claude Desktop、Claude Code 等 AI 應用程式可以讀取行情資料、執行篩選、讀取你儲存的自選清單和畫線，然後據此撰寫報告。它是唯讀的：沒有任何工具會下單或修改你的資料。

用 `--mcp` 參數啟動（此時它透過標準輸入/輸出通訊，不會開啟網頁介面）。把下面的內容加入 AI 應用程式的 MCP 設定，並換成 exe 的實際路徑：

```json
{
  "mcpServers": {
    "investerview": {
      "command": "C:\\path\\to\\Investerview.exe",
      "args": ["--mcp"]
    }
  }
}
```

如果從原始碼執行：`"command": "node", "args": ["C:\\path\\to\\server.js", "--mcp"]`。

| 工具 | 傳回內容 |
|---|---|
| `search_symbols` | 與公司名稱相符的代號 |
| `get_quote` | 價格、漲跌、成交量、RSI、均線、52 週位置、盤前盤後價格（最多 25 個代號） |
| `get_price_history` | 任意週期的 OHLCV K 線，可選擇包含盤前盤後 |
| `get_technicals` | SMA 20/50/200、EMA 20、RSI 14、MACD、布林通道 |
| `run_screener` | 對內建清單、你的自選清單或自訂清單進行篩選和排序 |
| `get_watchlist` | 依分組列出你的自選清單及報價 |
| `get_drawings` | 你儲存的畫線：線條、價格水平線、通道、部位、文字註記和費波那契水平 |
| `get_alerts` | 你的價格警示：等待中的和已觸發的 |

還有一個現成的提示詞 `watchlist_report`。也可以直接說：「根據我的 Investerview 自選清單寫一份晨報」。

自選清單和畫線工具讀取的是下文所述的資料檔，所以請先至少開啟一次桌面版。

## 盈透證券（IBKR）持倉（唯讀）

側邊欄的 **持倉** 分頁顯示你的 IBKR 帳戶：餘額、持倉及未實現損益、未成交委託單。在圖表上，持有的商品會在你的平均成本處顯示一條虛線，每筆未成交委託單會在其價格處顯示一條線。

它是唯讀的。應用程式只能向 IBKR 傳送固定的一組讀取請求（見 `server.js` 中的 `IB_READONLY`）；不能下單、改單或撤單。

每個交易日的設定步驟：

1. 下載 IBKR 的 **Client Portal Gateway**（見 IBKR 的 [Web API 文件](https://www.interactivebrokers.com/docs/web-api)）並解壓縮。它需要 Java 和 IBKR Pro 帳戶。
2. 在它的目錄中啟動：`bin\run.bat root\conf.yaml`
3. 在 <https://localhost:5000> 登入。瀏覽器在這裡提示憑證警告是正常的。使用模擬交易使用者名稱可以查看模擬帳戶。
4. 開啟「持倉」分頁並點選「重試」。

說明：

- 你的 IBKR 密碼只會輸入到 IBKR 自己的登入頁面；本應用程式不會接觸到它。
- 持倉和餘額只需要 IBKR 的唯讀工作階段，因此不會中斷 TWS 或手機端的登入。未成交委託單和當日損益只有在閘道中已有交易工作階段時才會顯示；本應用程式不會主動開啟交易工作階段。
- 閘道必須執行在同一台電腦上。如果你改了連接埠，請使用 `--ibkr=https://localhost:5001`（或 `IBKR_GATEWAY`）。
- IBKR 大約每天會讓閘道登出一次。
- MCP 服務不提供帳戶資料。

## 資料儲存在哪裡

在桌面版中，自選清單、畫線和指標設定儲存在瀏覽器裡，並同步到一個檔案：Windows 上是 `%APPDATA%\Investerview\data.json`，其他系統是 `~/.config/Investerview/data.json`（可用 `INVESTERVIEW_DATA` 修改）。啟動時以檔案為準，所以清除瀏覽器資料不會遺失，同一台電腦上的不同瀏覽器也共用這份資料。複製這個檔案即可備份或移到另一台電腦。

網頁版沒有資料檔：所有內容都只儲存在目前瀏覽器的本機儲存空間中。

## 資料來源和限制

- 價格來自 Yahoo Finance 的公開網頁介面，由 `server.js` 轉送；Yahoo 無法使用時改用備用資料來源（見「疑難排解」）。這些介面是非官方的、不受支援的：可能變更、限流或停止運作，報價也可能有延遲（部分交易所延遲 15–20 分鐘）。
- 日內歷史資料有限：1 分鐘 K 線約 5 天，5/15 分鐘 K 線約一個月，小時 K 線約 6 個月。
- 圖表函式庫（[Lightweight Charts](https://github.com/tradingview/lightweight-charts)，Apache-2.0）從 CDN 載入，因此應用程式需要連網。
- 上次查看的代號、週期和語言等圖表設定只儲存在瀏覽器的本機儲存空間中。
- 這只是一個看圖和篩選工具。它不會下單，其中任何內容都不構成投資建議。

## 疑難排解：沒有價格、「HTTP 403」或「被拒絕」

Yahoo Finance 會拒絕來自某些網路的請求：某些 VPN 出口、公司或學校代理伺服器、雲端主機和資料中心位址，以及部分地區。應用程式在放棄之前會嘗試四條路線（兩台 Yahoo 伺服器，各自帶或不帶工作階段 cookie），所以多數情況會自行恢復。如果圖表仍顯示「Yahoo Finance 拒絕了請求」：

- 開啟或關閉 VPN/代理，或換一個 VPN 節點，然後重新整理。
- 等幾分鐘：請求過多時 Yahoo 可能暫時封鎖某個位址。
- 開啟 `http://localhost:5178/api/diag`（即「查看連線診斷」連結），查看每條路線的回應結果。其中不含個人資料，求助時可以放心分享。

### 備用資料來源

當 Yahoo 拒絕請求或無法連線時，桌面版會自動切換到其他公開資料來源，圖表上會顯示「備用資料來源」標籤並註明目前使用的來源：

| 來源 | 涵蓋範圍 | 週期 |
|---|---|---|
| Binance，其次 Coinbase | 以美元計價的加密貨幣（`BTC-USD`） | 全部 |
| Nasdaq | 美股和 ETF | 日線、週線、月線（10 年） |

使用備用資料時的限制：美股沒有日內圖表（1 分鐘至 1 小時）；美國以外的股票、指數、外匯和期貨完全沒有資料；沒有盤前盤後價格，沒有代號搜尋（請直接輸入代號），也沒有公司名稱。價格可能與 Yahoo 略有差異（加密貨幣來自單一交易所；股利還原方式不同）。

1.5.0 版還包含一個實驗性的東方財富（Eastmoney）資料來源，用於指數、外匯、期貨和日內 K 線。它已在 1.5.1 中移除：東方財富在短時間的一小批請求之後把來源位址封鎖了三個多小時，無法作為備用資料來源使用。

應用程式直接連線 Yahoo。它不會使用只在瀏覽器或 Windows 設定中設置的代理；全域（TUN）模式的 VPN 則會生效。
