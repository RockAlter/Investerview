# InvestorView

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

トレード用スクリーニングアプリです。ブラウザ上でチャート表示と銘柄スクリーニングをローカルで行います。自分のパソコン上で動作し、アカウントや API キーは不要で、Node.js 以外の依存関係はありません。

- **デスクトップ版（全機能）：** [最新リリース](https://github.com/RockAlter/Investerview/releases/latest)から `InvestorView.exe` をダウンロードするか、下記の手順でソースから実行します。
- **ウェブ版：** <https://rockalter.github.io/Investerview/> — インストール不要。株式・ETF・指数・暗号資産に対応していますが、いくつか制限があります。[ウェブ版とその制限](#ウェブ版とその制限)を参照してください。

## 機能

- **チャート** — 13 種類：ローソク足、中空ローソク足、平均足、バー、HLC バー、高値-安値、ライン、マーカー付きライン、ステップライン、エリア、ベースライン、カラム、練行足（値幅は 14 本の ATR）。時間足は 1 分から 1 か月まで。通常・対数・パーセント・100 基準の価格スケール。
- **比較** — 他の銘柄を最大 4 つ、ラインとしてチャートに重ねられます（例: NVDA と SPY）。各ラインは画面左端で表示中の銘柄の価格から始まるため、そこからどちらが大きく動いたかが分かります。
- **マルチチャート** — 1 枚、2 枚（左右または上下）、4 枚のチャートを同時に表示できます。チャートごとに銘柄、時間足、チャートの種類、インジケーターを設定でき、描画は共有されます。チャートをクリックしてからウォッチリストの銘柄をクリックすると、そのチャートに表示されます。
- **アラート** — **アラート** タブで、銘柄に次のアラートを設定できます：
  - 価格が指定の水準に達したとき（チャートのその価格を右クリックしても追加できます。アラートはドラッグできる線としてチャートに表示されます）
  - 本日の上昇率・下落率が指定のパーセントに達したとき
  - 日足の RSI（14）が指定の値を上回った・下回ったとき
  - 価格が 50 日または 200 日移動平均を横切ったとき
  - 価格が自分で描いたトレンドラインや水平線を越えたとき：線を右クリックして「価格がこの線を越えたら知らせる」を選びます。線は描いた時間足の上で将来へ延長されます。

  アラートが発動すると、アプリがメッセージを表示して音を鳴らし、許可していれば Windows の通知も表示します。確認は約 20 秒ごとで、アプリを開いている間だけ行われます。
- **価格帯別出来高** — インジケーター一覧から追加できます。画面上のバーについて、価格帯ごとの出来高をチャート右端に横向きのヒストグラムで表示し（緑は陽線、赤は陰線）、出来高が最も多い価格（POC）を示します。
- **デモ口座のパフォーマンス** — デモタブに資産推移のグラフと、最大ドローダウン、勝率、平均利益・平均損失、プロフィットファクター、最大利益・最大損失、銘柄別の実現損益を表示します。
- **アクセスカウンター（Web 版のみ）** — Web 版は訪問のたびにデータプロキシへ通知し、データプロキシは匿名の日次集計（訪問数、訪問者数、新規訪問者数、国別の件数）だけを保存します。IP アドレス、Cookie、識別子は保存しません。デスクトップ版は何も送信しません。
- **時間外取引** — デスクトップ版は、株式と ETF の 1 分～ 1 時間足にプレマーケットとアフターマーケットの足（米国東部時間 4:00 ～ 20:00）を常に網掛けで表示します。ウォッチリストにも最新の時間外価格を表示します。夜間セッションはこのデータソースでは取得できません。
- **言語** — English、简体中文、繁體中文、日本語。ブラウザ／OS の言語に自動で合わせ、上部バーのセレクターで変更できます。翻訳は `public/i18n.js` にあります。
- **ライト／ダークテーマ** — システム設定に従います。上部バーの ☀ / ☾ ボタンで切り替え、選択を記憶します。
- **バージョン表示** — 実行中のバージョンを左ツールバーの下部に表示します。デスクトップ版は 1 日に 1 回ほど GitHub に最新のバージョン番号を問い合わせ、新しいバージョンがあると表示が `↑ v…` に変わり、ダウンロードページへのリンクになります。自動でダウンロードやインストールは行いません。
- **インジケーター** — 全25種類。価格チャート上：SMA、EMA、WMA、線形回帰線、VWAP、ボリンジャーバンド、ドンチャン・チャネル、ケルトナー・チャネル、スーパートレンド、パラボリック SAR、出来高。チャートの下：RSI、MACD、ストキャスティクス、CCI、ウィリアムズ %R、MFI、ADX/DMI、ATR、標準偏差、ROC、モメンタム、OBV。期間は変更できます。
- **描画ツール** — 全25種類を左ツールバーにグループ分け：ライン（トレンドライン、レイ、延長線、矢印、水平線、水平レイ、垂直線、十字線）、チャネル（平行チャネル、回帰チャネル ±2σ、アンドリューズ・ピッチフォーク）、フィボナッチとギャン（リトレースメント、エクステンション、ファン、タイムゾーン、ギャン・ファン）、図形（長方形、楕円、三角形）、計測（計測、価格レンジ、期間レンジ、リスク : リワード付きのロング／ショートポジション、アンカード VWAP）、テキスト。描画を選択してハンドルをドラッグすると調整できます。描画は銘柄ごとに保存され、時間足を変えても残ります。
  - **スタイル：** 描画を選択するとスタイルバーが表示され、色・線の太さ・実線／破線／点線を選べます。新しい描画は最後に選んだスタイルになります。
  - **マグネット：** 点が最寄りの足の始値・高値・安値・終値に吸着します（約 40 ピクセル以内）。
  - **連続描画** は描いた後もツールを選択したままにします（Esc で終了）。**ロック** で描画を選択・移動・削除できなくなり、**非表示** ですべての描画を隠します。
- **ペーパートレード** — サイドパネルの **デモ** タブに、仮想資金（初期 100,000、リセット可能）の練習用口座があります。表示中の銘柄を成行・指値・逆指値で売買（空売りも可）でき、ポジション、平均取得単価、実現・含み損益、約定履歴を確認できます。平均取得単価と待機中の注文はチャートに線で表示されます。証券会社には何も送信されません。注文はアプリが持つ最新価格で約定し（市場が閉まっていても同じ）、指値・逆指値はアプリを開いている間、約 20 秒ごとに確認されます。信用取引、手数料、通貨換算はありません。
- **ウォッチリスト** — セクション分け、ドラッグで並べ替え、最新価格と当日の変動をリアルタイム表示。**+ 追加** で任意の銘柄を検索して選んだセクションに入れられます。セクション見出しの **+** は表示中の銘柄をそのセクションに追加し、銘柄を右クリックすると別のセクションに移動できます。
- **インポート** — TradingView からエクスポートしたウォッチリスト（`取引所:銘柄` 形式のテキスト、`###セクション` 見出しを含む）を読み込み、銘柄コードを変換します。
- **スクリーナー** — 米国大型株、ETF、暗号資産、為替／コモディティ、日本大型株、自分のウォッチリスト、カスタムリストをスキャン。価格、騰落率、RSI、相対出来高、52 週高値からの距離、50 日／200 日移動平均との位置関係で絞り込めます。

## ウェブ版とその制限

<https://rockalter.github.io/Investerview/> は GitHub Pages で公開している同じ画面です。どのブラウザでも、インストールなしで開けます。

**価格の取得元。** ブラウザは、相手のサイトが明示的に許可しない限り、ウェブページが他のサイトのデータを読むことを認めません（CORS のルール）。Yahoo Finance、Nasdaq をはじめ多くの株価データ元は許可していないため、ウェブ版は複数のデータ元を使い、自動で切り替えます。失敗したデータ元は 2 分間スキップされ、次のデータ元が使われます：

| 順番 | データ元 | 対象 |
|---|---|---|
| 暗号資産 | Binance、次に Coinbase（ブラウザから直接） | 米ドル建ての暗号資産、全時間足 |
| 1 | **InvestorView データプロキシ** — ページの代わりに Yahoo Finance、Nasdaq、Tencent の順に問い合わせる小さな Cloudflare Worker（[`worker/`](worker/README.md)） | デスクトップ版で表示できるもの全部（分足・為替・先物・銘柄検索を含む） |
| 2 | Tencent Finance（ブラウザから直接） | 米国株と ETF、S&P 500 / ダウ / ナスダック / ハンセン指数、香港株と中国 A 株。日足・週足・月足 |
| 3 | 公開プロキシ AllOrigins 経由の Yahoo Finance | すべて。ただし遅く、使えないことも多い |

使用中のデータ元はチャート上部の凡例の行に表示されます。

| | ウェブ版 | デスクトップ版 |
|---|---|---|
| 株式・ETF・指数・暗号資産（日足・週足・月足） | 対応 | 対応 |
| 分足チャート（1 分〜1 時間）・為替・先物・銘柄検索 | データプロキシ（または AllOrigins）に接続できる間は対応。暗号資産の分足は常に対応 | 対応 |
| 時間外取引の価格 | 非対応 | 対応 |
| スクリーナー | すべての組み込みリスト | すべての組み込みリスト |
| ウォッチリストの読み込み | 非対応 | 対応 |
| IBKR のポジションと注文 | 非対応 | 対応 |
| AI アプリ用 MCP サーバー | 非対応 | 対応 |
| ウォッチリストと描画の保存先 | そのブラウザのみ：バックアップされず、他のブラウザ・端末・デスクトップ版とは共有されません | ブラウザとディスク上のデータファイル |
| チャートの種類・インジケーター・描画ツール・言語・テーマ | 対応 | 対応 |

ウェブ版について、その他の注意点：

- 予備データ元の価格は Yahoo とわずかに異なることがあります（暗号資産は単一の取引所の価格、配当の調整方法も異なります）。また予備データ元では会社名ではなくティッカーが表示されます。
- **スマートフォンでは**、画面下部のタブバーで、チャート・ウォッチリスト・アラート・模擬口座・スクリーナーを切り替えて 1 つずつ表示します。上部バーには検索・更新・時間足が残り、その他のチャート設定は **⋯** の中にあります。右クリックの代わりに長押ししてください。iPhone では Safari の共有 →「**ホーム画面に追加**」で、アプリのように全画面で開けます。
- ウェブ版は `gh-pages` ブランチに公開している `public/` フォルダです。`public/web-data.js` がデータ層で、その先頭の `PROXY_URL` がデータプロキシのアドレスです。

## 実行方法

[Node.js](https://nodejs.org) 18 以降が必要です。

```bash
node server.js
```

その後 <http://localhost:5178> を開きます。Windows では `start.bat` をダブルクリックしても起動できます。別のポートを使うには環境変数 `PORT` を設定します。

## 単体の .exe をビルドする

Node.js を持っていない人にアプリを渡すには、単一ファイルの実行ファイルをビルドします。

```bash
npm run build
```

`dist/InvestorView.exe`（約 80 MB。Node ランタイムを含むため）が作成されます。ビルド時に補助ツール [postject](https://github.com/nodejs/postject) を `npx` 経由でダウンロードします。ビルド時には、exe にアイコンと名前を設定するための [rcedit](https://github.com/electron/rcedit) も `npm` 経由でダウンロードします。exe をダブルクリックすると、アプリが専用のウィンドウで開きます（コンソールもブラウザのタブもありません）。ウィンドウを閉じるとアプリは終了します。このウィンドウはアプリモードの Microsoft Edge（Windows に付属）または Chrome で、専用のブラウザプロファイルを使います。どちらもない場合、または `--browser` を付けた場合は既定のブラウザで開き、ページを閉じてから 10 分後に自動で終了します。

この exe にはコード署名がないため、初回実行時に Windows SmartScreen の警告が表示されます（「詳細情報」→「実行」）。

## AI アプリから使う（MCP）

同じプログラムは [Model Context Protocol](https://modelcontextprotocol.io) サーバーとしても動作します。Claude Desktop や Claude Code などの AI アプリが市場データの取得、スクリーニングの実行、保存済みのウォッチリストや描画の読み取りを行い、それをもとにレポートを作成できます。読み取り専用で、注文を出したりデータを変更したりするツールはありません。

`--mcp` を付けて起動します（標準入出力で通信し、ウェブアプリは開きません）。AI アプリの MCP 設定に、exe の実際のパスを入れて次を追加してください。

```json
{
  "mcpServers": {
    "investerview": {
      "command": "C:\\path\\to\\InvestorView.exe",
      "args": ["--mcp"]
    }
  }
}
```

ソースから実行する場合：`"command": "node", "args": ["C:\\path\\to\\server.js", "--mcp"]`

| ツール | 返す内容 |
|---|---|
| `search_symbols` | 会社名に一致する銘柄コード |
| `get_quote` | 価格、変動、出来高、RSI、移動平均、52 週レンジ内の位置、時間外価格（最大 25 銘柄） |
| `get_price_history` | 任意の時間足の OHLCV データ（時間外取引を含めることも可能） |
| `get_technicals` | SMA 20/50/200、EMA 20、RSI 14、MACD、ボリンジャーバンド |
| `run_screener` | 組み込みリスト、自分のウォッチリスト、カスタムリストを絞り込み・並べ替え |
| `get_watchlist` | セクションごとのウォッチリストと価格 |
| `get_drawings` | 保存済みの描画：ライン、価格水準、チャネル、ポジション、テキストメモ、フィボナッチ水準 |
| `get_alerts` | アラート（価格・本日の騰落率・RSI・移動平均・描いた線）：待機中のものと発動済みのもの |

`watchlist_report` という既製のプロンプトもあります。「InvestorView のウォッチリストで朝のレポートを書いて」と頼むだけでも使えます。

ウォッチリストと描画のツールは後述のデータファイルを読み取るため、先にデスクトップ版を一度は開いておいてください。

## Interactive Brokers のポジション（読み取り専用）

サイドパネルの **ポジション** タブに IBKR 口座の残高、ポジションと含み損益、未約定注文を表示します。チャート上では、保有銘柄の平均取得単価に破線を、未約定注文ごとにその価格に線を表示します。

読み取り専用です。アプリが IBKR に送れるのは決められた読み取りリクエストのみで（`server.js` の `IB_READONLY` を参照）、注文の発注・変更・取消はできません。

取引日ごとの準備：

1. IBKR の **Client Portal Gateway** をダウンロードして解凍します（IBKR の [Web API ドキュメント](https://www.interactivebrokers.com/docs/web-api)を参照）。Java と IBKR Pro 口座が必要です。
2. そのフォルダーで起動します：`bin\run.bat root\conf.yaml`
3. <https://localhost:5000> でログインします。ここでブラウザに証明書の警告が出るのは正常です。ペーパートレード用のユーザー名を使うとペーパー口座が表示されます。
4. 「ポジション」タブを開いて「再試行」を押します。

注意点：

- IBKR のパスワードは IBKR 自身のログインページにのみ入力します。このアプリがパスワードを扱うことはありません。
- ポジションと残高には IBKR の読み取り専用セッションだけで足りるため、TWS やモバイルのログインは中断されません。未約定注文と当日損益は、ゲートウェイで取引セッションがすでに有効な場合のみ表示されます。アプリが取引セッションを開始することはありません。
- ゲートウェイは同じパソコン上で動かす必要があります。ポートを変更した場合は `--ibkr=https://localhost:5001`（または `IBKR_GATEWAY`）を使ってください。
- IBKR は 1 日に 1 回程度ゲートウェイをログアウトさせます。
- MCP サーバーは口座データを公開しません。

## データの保存場所

デスクトップ版では、ウォッチリスト、描画、インジケーター設定はブラウザに保存され、ファイルにも同期されます。Windows では `%APPDATA%\Investerview\data.json`、それ以外では `~/.config/Investerview/data.json` です（`INVESTERVIEW_DATA` で変更可能）。起動時はファイルの内容が優先されるため、ブラウザのデータを消去しても残り、同じパソコン上の複数のブラウザで共有されます。このファイルをコピーすれば、バックアップや別のパソコンへの移行ができます。

ウェブ版にはデータファイルがなく、すべてそのブラウザのローカルストレージにのみ保存されます。

## データソースと制限

- 価格は Yahoo Finance の公開ウェブエンドポイントから取得し、`server.js` が中継します。Yahoo が利用できない場合は予備のデータソースを使います（「トラブルシューティング」を参照）。これらは非公式でサポート対象外のため、変更・レート制限・停止の可能性があり、価格が遅延することもあります（取引所によっては 15 ～ 20 分）。
- 日中足の履歴には限りがあります：1 分足は約 5 日、5 分／15 分足は約 1 か月、1 時間足は約 6 か月。
- チャートライブラリ（[Lightweight Charts](https://github.com/tradingview/lightweight-charts)、Apache-2.0）は CDN から読み込むため、インターネット接続が必要です。
- 最後に表示した銘柄、時間足、言語などのチャート設定は、ブラウザのローカルストレージにのみ保存されます。
- これはチャート表示とスクリーニング専用のツールです。注文は行わず、内容はいずれも投資助言ではありません。

## トラブルシューティング：価格が表示されない、「HTTP 403」、「拒否されました」

Yahoo Finance は一部のネットワークからのリクエストを拒否します。特定の VPN の出口、企業や学校のプロキシ、クラウドやデータセンターのアドレス、一部の地域などです。アプリはあきらめる前に 4 つの経路（Yahoo の 2 つのサーバーそれぞれについて、セッション Cookie あり・なし）を試すため、多くの場合は自動的に回復します。それでもチャートに「Yahoo Finance がリクエストを拒否しました」と表示される場合：

- VPN やプロキシをオン／オフするか、VPN の接続先を変えて再読み込みします。
- 数分待ちます。リクエストが多いと Yahoo がアドレスを一時的にブロックすることがあります。
- `http://localhost:5178/api/diag`（「接続診断を表示」リンク）を開き、各経路の応答を確認します。個人データは含まれないので、助けを求める際に共有しても安全です。

### 予備のデータソース

Yahoo がリクエストを拒否するか接続できない場合、デスクトップ版は自動的に他の公開ソースに切り替え、チャートに使用中のソース名を示す「予備データ」タグを表示します。

| ソース | 対象 | 時間足 |
|---|---|---|
| Binance、次に Coinbase | 米ドル建ての暗号資産（`BTC-USD`） | すべて |
| Nasdaq | 米国株と ETF | 日足、週足、月足（10 年分） |

予備データ使用中の制限：米国株の日中足（1 分～ 1 時間）は表示できません。米国外の株式、指数、為替、先物のデータは一切ありません。時間外価格、銘柄検索（銘柄コードを直接入力してください）、会社名もありません。価格は Yahoo とわずかに異なることがあります（暗号資産は単一の取引所の価格で、配当調整の方法も異なります）。

バージョン 1.5.0 には、指数・為替・先物・日中足用の試験的な Eastmoney（東方財富）ソースもありましたが、1.5.1 で削除しました。短時間に少数のリクエストを送っただけでアドレスが 3 時間以上遮断され、予備ソースとして使えないためです。

アプリは Yahoo に直接接続します。ブラウザや Windows の設定だけで構成したプロキシは使われません。フルトンネル（TUN）モードの VPN は適用されます。
